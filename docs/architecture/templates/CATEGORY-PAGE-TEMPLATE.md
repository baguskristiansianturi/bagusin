# Category page template rules

Use the approved structure in `collections/landing-page/index.html` as the visual reference for:
- breadcrumb (exactly one)
- hero title and short sales-focused copy
- function labels
- sticky horizontal industry carousel
- result area / category-specific empty state
- explanatory section
- shared footer

For Company Profile and Website Kompleks, copy the page template and change only the page-specific title, metadata, sales copy, function labels, empty-state wording and descriptive section. Keep the industry taxonomy identical across all three.

Do not create a Complete Business category page in this phase. Do not redesign the homepage while creating or updating category pages.
