Learn Web Developer step by step.

Learn to build websites from fundamentals to deployment. The curriculum moves from foundations to a practical project, with emphasis on understanding decisions—not just following tools.

Foundation to practicePortfolio-ready projectSchedule confirmed before enrolment

Who it is for

Designed around your next step

Beginners, students, career changers, and business owners who want to understand technical work.

Starting point

No advanced background is assumed for the foundation modules. A computer and time for regular practice are recommended; hardware-specific requirements will be confirmed for relevant modules.

Learning outcomes

What you will work toward

  • Build responsive pages with HTML and CSS
  • Add interactions with JavaScript
  • Track code changes with Git
  • Build and deploy a web project
Structured syllabus

Curriculum, module by module

This is the learning roadmap. The final lesson plan, delivery format, duration, and any prerequisites will be confirmed before enrolment.

01Foundations and contextModule 1+

Topics covered

Cara kerja browser, internet, URL, HTML, CSS, dan JavaScript.

02Core skills and workflowModule 2+

Topics covered

Struktur semantik, layout, responsivitas, aksesibilitas, dan styling.

03Applied methodsModule 3+

Topics covered

Variabel, fungsi, kondisi, array, DOM, event, dan debugging.

04Tools and practiceModule 4+

Topics covered

Repository, commit, branch, dan kolaborasi dasar.

05Building and integrationModule 5+

Topics covered

Komponen, data, dan pengenalan framework setelah fondasi kuat.

06Quality and evaluationModule 6+

Topics covered

HTTP, API, validasi, SQL, dan konsep penyimpanan data.

07Project and deliveryModule 7+

Topics covered

Pemeriksaan, performa dasar, keamanan dasar, dan publikasi proyek.

Practical work

Learn by building something useful.

The course should end with a concrete artifact that demonstrates the skills practised. The exact brief can be adjusted to the learner’s goal and starting level.

Suggested capstone

A responsive multi-page website deployed publicly.
