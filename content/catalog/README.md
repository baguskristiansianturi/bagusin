# Catalogue data

This directory is reserved for normalized catalogue metadata and the shared industry taxonomy. Existing catalogue JSON and page entry points remain in place until a migration updates every consumer.

## Rules
- Use one stable industry ID across Company Profile, Landing Page and Website Kompleks.
- Keep labels and page copy separate from the industry list.
- Do not add Complete Business as a category page in the current phase; its future page is intentionally out of scope.
- Before moving catalogue data, search every JavaScript fetch, HTML attribute, filter and test that consumes it.
