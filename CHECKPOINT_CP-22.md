# CHECKPOINT CP-22 — Relevant Image Placeholders

Date: 2026-10-06

Visual areas that are clearly designed to contain photography now start with relevant temporary images instead of empty gradients/placeholders.

Covered:
- homepage story visuals
- Places destination visuals
- Work / portfolio evidence visuals
- article recommendation media
- YouTube latest-video media before the first video exists

The images are intentionally temporary. They can be replaced later by updating the image URL or, preferably, by local project assets without changing the component/layout.

No content rail, hero-height or navigation behavior was changed in this checkpoint.

Manual browser QA remains required, including checking image loading and crop behavior at 320, 375, 390, 768, 1024 and 1440px.
