# Bagusin Master Curriculum — Source of Truth

**Status:** Master curriculum / staged implementation plan. This file defines the scope; it must not be reduced to the currently available course detail pages.

## Product intent
Modernise the traditional computer-course model into a modern, connected digital-skills learning ecosystem. Preserve the practical value of legacy topics while extending the curriculum into contemporary software engineering, cloud, AI, automation, data and connected devices. The original Computer Course Center website is a reference for breadth of learning topics, not a source to copy verbatim. Rewrite and reorganise content in Bagusin's own structure and voice.

## Learners
- Small-business owners and UMKM who want to understand, operate or improve their own digital tools.
- Employees and teams who need practical workplace skills.
- Freelancers who want to build services and a portfolio.
- Students and younger learners who need a guided foundation.
- Independent learners who want a structured path from beginner to advanced.

Learners select by intended outcome and current ability, not only by software name.

## The 16 curriculum domains
Each domain must be mapped through **Foundation → Intermediate → Advanced → Professional**. Prerequisites should be explicit. Levels are competency stages, not promises of a fixed duration or certificate.

1. **Digital Foundations** — computer basics, operating systems, file management, internet/email, digital safety, Office, Google Workspace and productivity.
2. **UI/UX & Web Design** — visual fundamentals, user research, information architecture, wireframes, prototypes, responsive UI, accessibility and design systems.
3. **Frontend Development** — semantic HTML, CSS, responsive layout, JavaScript, DOM/events, APIs, Git, frameworks, testing, performance and accessibility.
4. **Programming & Algorithms** — computational thinking, algorithms, data structures, programming fundamentals, debugging, OOP, complexity, testing and maintainable code.
5. **Backend Development** — HTTP, server-side programming, routing, validation, REST APIs, authentication/authorization, databases, testing, security, logging and reliability.
6. **Database & Data Engineering** — data modelling, SQL, relationships, joins, aggregation, normalisation, indexes, query tuning, ETL/ELT, data quality, warehouse/lakehouse concepts and governance.
7. **CMS & Web Platforms** — domain/hosting, CMS operations, WordPress, themes/plugins, Blogger template development, SEO, backups, security, migration and maintainability.
8. **Cloud Computing** — cloud concepts, compute/storage/networking, IAM, managed services, Google Cloud and other provider concepts, deployment, reliability, disaster recovery and cost governance.
9. **DevOps & Security** — terminal/Linux, Git workflows, CI/CD, containers, infrastructure as code, secrets, vulnerability awareness, monitoring, incident response, SRE and secure delivery.
10. **AI & Machine Learning** — AI literacy, prompting, data preparation, evaluation, ML concepts, model/API integration, retrieval/embeddings, responsible AI, MLOps and governance.
11. **Automation & Integration** — process mapping, spreadsheets, Excel Macro/VBA, Google Apps Script, no-code workflows, APIs, webhooks, retries, logging, orchestration and auditability.
12. **Mobile Development** — mobile UX, platform foundations, navigation/forms, storage, APIs, authentication, state, offline handling, testing, release and monitoring.
13. **Embedded Systems & IoT** — electronics basics, sensors/actuators, microcontrollers, firmware, device communication, MQTT/HTTP, cloud integration, device security and fleet operations.
14. **Computer & Networking** — components, operating systems, assembly/troubleshooting, BIOS/UEFI, LAN, IP/subnetting, DNS/DHCP, Wi-Fi, routers, recovery, firewalls and network security.
15. **Data Analysis & Business Tools** — Excel, Google Sheets, formulas, lookup, pivot tables, cleaning, charts, SQL, descriptive statistics, Looker Studio/BI, KPIs and business storytelling.
16. **Graphic Design & Media** — composition, typography, colour, Photoshop/image editing, graphic design, social assets, animation/video editing, 3D/SketchUp, AutoCAD and production workflows.

## Cross-domain learning pathways
1. **Web & Software Engineering:** digital foundations → algorithms → UI/UX or frontend → backend → database → testing → deployment; CMS is an optional specialisation.
2. **Cloud & Infrastructure:** computer/network foundations → terminal/Linux → cloud → deployment → DevOps → security/monitoring/reliability.
3. **AI Engineering:** programming → data foundations → AI/ML → APIs/integration → evaluation → deployment, governance and monitoring.
4. **IoT & Connected Systems:** electronics → embedded programming → sensors/device protocols → networking → cloud/data integration → security.
5. **Data & Automation:** spreadsheets → data cleaning → SQL/analytics → dashboards → process mapping → automation/API → measurement/governance.

These topics should be mapped into the 16 domains and may become standalone courses, modules, short courses or practice projects. Do not silently delete them just because a modern domain has a different name.

## Teaching model
Every course page should eventually state:
- Intended learner and entry prerequisites.
- Practical outcomes in plain language.
- Ordered modules with topics and practice.
- Small exercises, a project brief, feedback/revision and a final portfolio artefact where appropriate.
- What the learner can do next and prerequisites for that next step.
- Learning method, expected time commitment, equipment/software requirements and assessment approach once confirmed.
- Clear availability state.

A recommended practice loop is: **Understand → See an example → Practise → Modify → Solve a challenge → Receive feedback → Build a project → Review**.

## Honest status and trust
Never imply that all 16 domains or every level is already open for enrolment. Distinguish:
- **Available:** confirmed to run and with verified details.
- **In development:** curriculum/page being built; registration availability not promised.
- **Planned:** mapped but not yet developed into a course.
Do not invent instructors, schedules, pricing, testimonials, certifications, accreditation or outcomes. Certificates are not the primary promise; demonstrated practical competence and projects matter.

## Practice and assessment pattern

All 16 course-detail pages (eight Indonesian and eight English) now include the same transparent practice loop: understand an example → guided practice → independent challenge → review and improve. Assessment is framed around completed exercises, reasoning, revision and a final project. Course-specific private pricing, meeting count and session duration must be shown before registration. The pricing rule is: the relevant benchmark package price + Rp1,750,000 for Bagusin's one-to-one private model. Use a clearly named nearest reference only when no identical course exists; never imply the reference provider offers the same curriculum. For tracks without a defensible comparison, mark the amount as a planning estimate and keep enrolment closed until reviewed. Offline learning means the instructor visits the learner's home/chosen location in Bali within an agreed service area; Bagusin has no physical classroom. In-person sessions can be around 50% more intensive in hands-on practice based on learner needs and agreed scope. Online learning can be delivered from anywhere. Each page must state device prerequisites, starting competency, meeting-by-meeting syllabus, practical outcome, exclusions such as software/ad spend/cloud fees/hardware kits, and honest availability.


## Binding private-learning and pricing policy (2026-10-11)

- **Delivery:** one learner per instructor. Online is available from anywhere. In-person sessions are instructor visits to the learner's home/chosen location in Bali, subject to service area and schedule agreement. Never describe Bagusin as having its own classroom.
- **Readiness:** eligibility is based on demonstrated skills, never age. Learners who cannot confidently use a computer start with Digital Foundations. Website/programming/data/cloud/design practice requires a suitable laptop/desktop; a phone alone is not enough.
- **Price formula:** Bagusin course price = relevant benchmark package price + **Rp1,750,000** for private one-to-one instruction. State the comparison package and make clear when it is a nearest reference rather than an identical curriculum. Do not identify Computer Course Center as a Bagusin service, partner or product.
- **Disclosure:** every course page shows total price, number of meetings, duration per meeting, prerequisites, required devices/software, ordered syllabus for every meeting, final practical outcome and what is excluded. Third-party licences, ad budgets, cloud usage and hardware kits must not silently be included.
- **Availability:** distinguish confirmed/available courses from development estimates and planned pathways. A development estimate is not an open booking. Never fabricate instructor availability, certificates, accreditation or guaranteed career outcomes.
- **Curriculum scope remains binding:** retain all 16 domains, four levels (Foundation, Intermediate, Advanced, Professional), five cross-domain pathways and all 37 legacy topic families. The 8 current detail pages are starting pathways, not the complete course catalogue.
