# Product assets

Place approved, product-specific images and logos here.

Suggested structure:
- `images/hero/`
- `images/gallery/`
- `images/artists/`
- `images/studio/`
- `icons/`
- `fonts/` (only when the licence permits redistribution)

Keep asset files inside this product folder. Do not put product-specific assets in Bagusin's global `assets/` directory. Use descriptive filenames and document recommended crop ratios in `product.json`.

The current demo references remote Unsplash images from the page markup. When preparing a customer ZIP, download or replace these with client-owned/licensed local files and update the image paths.
